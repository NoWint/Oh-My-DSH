## ⚡ 安装方式速查

```sh
# npm 一键安装（部分插件）
npm install -g <plugin-package>

# 通过 dsh CLI 安装 repository 插件
dsh plugin --profile web add github:owner/repo#ref&path:/<plugin-path>

# Python SDK 驱动
pip install deepseek-harness-sdk
```
